## Project Overview
This project is a café-themed website developed as part of Lab 12. It provides visitors with an attractive and user-friendly way to explore the café, view its menu, browse food and café images, and find contact information.

## Website Theme
**Cafe**

A modern café website designed to showcase café products, atmosphere, menu items, and contact details.

## Website Pages

1. **Home (`index.html`)** – Introduces the café and welcomes visitors.
2. **Menu (`menu.html`)** – Displays the café's food and drink menu.
3. **Gallery (`gallery.html`)** – Showcases images of the café and its offerings.
4. **Contact (`contact.html`)** – Provides contact information for visitors.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
